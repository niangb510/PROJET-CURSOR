# Portfolio de N'Baye Niang

Bienvenue sur le dépôt de mon portfolio professionnel. Ce projet est une vitrine immersive présentant mon parcours, mes compétences et mes réalisations en tant que développeur web, avec une spécialisation en solutions logistiques.

🚀 **Lien du site hébergé : [https://portefoliobaye.netlify.app/](https://portefoliobaye.netlify.app/)**

## 👤 À propos

Je suis **N'Baye Niang**, étudiant à **Epitech**. Mon approche combine une compréhension approfondie de la Supply Chain (Vision Logistique) avec une force technique pour traduire les besoins métiers en solutions applicatives performantes, sécurisées et scalables.

## 🛠️ Stack Technique

Ce portfolio a été conçu pour offrir une expérience utilisateur fluide et esthétique en utilisant des technologies modernes :

- **Frontend core** : HTML5, JavaScript (ES6+)
- **Styling** : [Sass (SCSS)](https://sass-lang.com/) pour une gestion modulaire des styles
- **Animations & 3D** : 
  - [GSAP](https://greensock.com/gsap/) pour les micro-interactions et révélations au scroll
  - [Three.js](https://threejs.org/) pour les éléments visuels immersifs
- **Build Tool** : [Vite](https://vitejs.dev/) pour un environnement de développement ultra-rapide et une optimisation de build
- **Hébergement** : Netlify

## 📂 Structure du Projet

Le site est structuré en plusieurs sections clés pour répondre aux exigences du titre RNCP :

## 🚀 Installation Locale

Pour lancer le projet sur votre machine :

1.  **Cloner le dépôt** :
    ```bash
    git clone https://github.com/votre-utilisateur/votre-repo.git
    cd votre-repo
    ```

2.  **Installer les dépendances** :
    ```bash
    npm install
    ```

3.  **Lancer le serveur de développement** :
    ```bash
    npm run dev
    ```

4.  **Builder pour la production** :
    ```bash
    npm run build
    ```
